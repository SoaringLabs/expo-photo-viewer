# Changelog

## 0.2.1

- Use interactive Liquid Glass for the page counter on iOS 26 and later.
- Use a shared dark appearance for the page counter and standard close button in the fullscreen viewer.
- Keep the close button circular and its symbol steady during press feedback.

## 0.2.0

- Use the standard UIKit close button by default and allow apps to customize its symbol, tint, and background.
- Animate the current page number when paging and honor Reduce Motion.
- Center the page counter and fade the controls when tapping the photo.
- Remove the caption option from the gallery.

## 0.1.0

- Added the iOS 18+ fullscreen UIKit photo gallery for Expo SDK 58.
- Added thumbnail zoom transitions, horizontal paging, pinch zoom, and interactive downward dismissal.
- Added lazy loading from app-provided local files, custom labels, and an example app.
